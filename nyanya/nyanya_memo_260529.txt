[ 페이지 이름 ]
  이유식 트래커 (Iyushik Tracker)

----------------------------------------------------------------
[ 목적 ]
  영아의 이유식 섭취 기록을 달력 기반으로 관리하고,
  만들어 둔 이유식 재고를 추적·관리하는 모바일 친화적 웹앱.
  별도 서버 없이 localStorage만으로 동작하는 오프라인 PWA 형태.

----------------------------------------------------------------
[ 주요 기능 / 탭 구성 ]

  1. 달력 기록 탭 (기본 화면)
     - 월별 달력으로 날짜별 섭취 이유식 확인
     - 날짜 셀에 재료 도트(색상 점)와 총 섭취량(g) 표시
     - D+ 카운터: 아기 생후 일수 달력에 자동 표시
     - 날짜 클릭 시 하단 패널에 당일 상세 기록 노출
     - + 편집 버튼으로 재료 추가·수정·삭제
     - 이달 처음 먹인 재료 범례(첫 시작 재료) 자동 표시
     - 통계 띠: 오늘 재료 수 / 오늘 총량 / 생후 일수 / 이달 기록일 / 만료임박 재고 수

  2. 이유식 재고 탭
     - 만들어 둔 이유식 등록 (이름, 재료, 제작일, 사용기한, 개수)
     - 남은 개수 +/- 버튼으로 실시간 차감
     - 사용기한 임박 시 카드 색상 자동 변경 (정상 → 경고 → 위험)
     - 재고 수정 / 삭제 기능

  3. 아기 정보 탭
     - 이름, 생년월일, 알레르기, 특이사항 입력·저장
     - 생년월일 기준 개월 수 자동 계산 → 헤더에 표시
     - D+ 카운터 연동 (달력 탭에 반영)

  4. 튜토리얼
     - 첫 실행 시 자동 시작 (localStorage로 완료 여부 관리)
     - ? 버튼으로 언제든 재실행
     - 3단계 스텝: 달력 기록 → 이유식 재고 → 아기 정보
     - SVG 마스크로 현재 설명 영역만 하이라이트

----------------------------------------------------------------
[ 기술 스택 ]
  - HTML5 / CSS3 / Vanilla JS (프레임워크 없음)
  - localStorage: 데이터 영속성 (서버 불필요)
  - CSS 변수(Custom Properties): 핑크-옐로우 컬러 테마
  - Paperlogy 웹폰트 (CDN)
  - env(safe-area-inset): iOS 노치·홈바 대응
  - SVG 마스크: 튜토리얼 하이라이트 효과
  - position: sticky: 헤더+탭 고정 스크롤

----------------------------------------------------------------
[ 디자인 포인트 ]
  - 모바일 퍼스트 (기준 너비 560px, 데스크탑은 중앙 카드형)
  - 핑크(#F48FB1) + 옐로우(#FFD54F) 파스텔 투톤 테마
  - 모든 터치 타겟 min-height 44px 준수
  - 소형(480px 이하) / 초소형(360px 이하) 반응형 분기 처리
  - 바텀 시트 형태 모달 (border-radius 24px 24px 0 0)
